# A. アプリの目的

`C:\Users\noyam\Desktop\オークションポーカー\使用カード` のAI生成カード画像は、\
生成のたびにレイアウトが微妙にずれている。\
本アプリは、これらの画像を読み込み、共通テンプレートに合わせてレイアウトを統一する。

対象要素は以下4つ。

- ①外枠
- ②タイトル
- ③イラスト
- ④説明文

# B. カード要素の設計

## ①外枠

- `image/黒枠線テンプレート.png`を外枠として読み込む
- ②③④の表示矩形は、アプリ内に固定座標として定義する

## ②タイトル

- 元画像のタイトル領域からWindows OCR(Windows.Media.Ocr)で文字列を抽出する
  → 抽出領域はアプリ内で指定可能にする
- 抽出結果はテキストボックスで表示し、編集可能にする
- タイトル表示領域に、水平・垂直共に中央揃えで描画する

### 統一レイアウト設定(アプリ全体設定)

- フォント種類、サイズ
- 1文字ごとの間隔(px)

### 個別調整

- テキストボックスで文字範囲選択→「調整」ボタンでダイアログを開く
- ダイアログでフォント種類・サイズ・文字間隔を個別に上書きできる
- 「クリア」で統一レイアウト設定に戻す

## ③イラスト

- 元画像のイラスト領域を矩形で切り抜く
- イラスト表示矩形に、切り抜いた画像を貼り付ける
- 縦横比キープの有無をラジオボタンで選択する(初期値：キープしない)
  → キープする場合、余った側は中央揃えで表示する

## ④説明文

②タイトルと共通処理として実装する。\
以下の点が②と異なる。

- 水平は左揃え、垂直は中央揃えで描画する
- 複数行に対応する

### 統一レイアウト設定(アプリ全体設定)

- フォント種類、サイズ
- 1文字ごとの間隔(px)
- 1行ごとの間隔(px)

### 個別調整

②タイトルと同様。\
行間隔も個別調整の対象に含める。

# C. 画面設計

## 全体レイアウト

4カラム構成にする。

1. カード一覧 : 使用カードフォルダ内の画像をリスト表示し、選択で編集対象を切り替える
2. 元画像 : 選択中カードの生画像を表示する
3. プレビュー : ①～④を合成した完成イメージを表示する
4. 要素操作 : ②③④それぞれの「読取」「調整」ボタンとテキストボックス

## 領域のドラッグ調整

- ②③④の領域は、元画像上でドラッグして位置調整できる
- 初期表示位置は、プレビューの矩形位置(固定座標)と同じにする

## プレビューの更新タイミング

- ②タイトル、④説明文 : テキストボックスの内容に連動してリアルタイム更新する
- ③イラスト : 「読取」ボタンを押したときのみ更新する

# D. 保存

- 「保存」ボタンで、完成したカード画像をPNGとして指定先に保存する
- フォルダ一括処理は今回のスコープ外とする(1枚ずつの個別保存)

# E. カードフォルダの設定

- 起動時に読み込むカードフォルダパスは`config.ini`で設定できる
  → 既定値は`C:\Users\noyam\Desktop\オークションポーカー\使用カード`

# タスク1 - プロジェクト基盤構築とカード一覧表示

[完了イメージ]
- WPFプロジェクトの雛形が作成されている(MVVM構成、CommunityToolkit.Mvvm)
- 起動時に使用カードフォルダ(config.ini設定)を読み込み、
  カード一覧がリスト表示される
- カードを選択すると元画像・プレビュー欄に表示される
  (プレビューはこの時点では元画像そのまま表示でよい)
- 画面レイアウトが4カラム構成
  (カード一覧／元画像／プレビュー／要素操作)になっている
  → 要素操作カラムは後続タスクで追加するため、本タスクでは未着手でよい

# タスク2 - ①外枠のテンプレート合成

[完了イメージ]
- テンプレート画像(`image/黒枠線テンプレート.png`)を外枠として読み込む
- ②③④の表示矩形を固定座標で定義しておく
- プレビューに外枠のみ合成された状態が表示される

# タスク3 - ②タイトルのOCR抽出・編集・描画

[完了イメージ]
- 要素操作カラムに「タイトル」欄(テキストボックス、読取・調整ボタン)が追加される
- 「読取」ボタンでタイトル領域からWindows OCRを実行し、テキストボックスへ反映する
- テキストボックスの内容を変更すると、プレビューのタイトルがリアルタイム更新される
- タイトルは表示領域に水平・垂直共に中央揃えで描画される
- フォント種類・サイズ、文字間隔pxをアプリ設定として保持する
  → タスク5(④説明文)の設定とは別に保持する(初期値はより大きいサイズ)

# タスク4 - ③イラストの切り抜き・貼り付け

[完了イメージ]
- 要素操作カラムに「イラスト」欄(読取・調整ボタン)が追加される
- 「読取」ボタンでイラスト領域を矩形切り抜きし、表示矩形に貼り付ける
- 縦横比キープ有無をラジオボタンで選択できる(初期値：キープしない)
- キープする場合、余った側が中央揃えになる

# タスク5 - ④説明文のOCR抽出・編集・描画(②と共通化)

[完了イメージ]
- 要素操作カラムに「説明文」欄(テキストボックス、読取・調整ボタン)が追加される
- タスク3の共通処理を再利用して実装する
- 水平は左揃え、垂直は中央揃えで描画され、複数行に対応する
- フォント種類・サイズ、文字間隔px、行間隔pxをアプリ設定として保持する
  → タスク3(②タイトル)の設定とは別に保持する(初期値はより小さいサイズ)

# タスク6 - 個別調整ダイアログ

[完了イメージ]
- テキストボックスで文字範囲選択→「調整」ボタンでダイアログが表示される
- フォント種類・サイズ・文字間隔(・行間隔)を個別に上書き設定できる
- 「クリア」で統一設定に戻せる

# タスク7 - 領域のドラッグ調整

[完了イメージ]
- 元画像上で②③④の領域をドラッグして位置調整できる
- 初期表示位置はプレビューの矩形位置と同じになる

# タスク8 - 個別保存

[完了イメージ]
- 「保存」ボタンで、完成したカード画像をPNGとして指定先に保存できる

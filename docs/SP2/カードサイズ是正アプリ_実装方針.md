前提 : 同フォルダのカードサイズ是正アプリ_仕様書.md(SP2版)を前提とする。

# 実装タスク

以下のタスク単位でIssueを切る。\
MRはその中の機能単位で切る。

ブランチ名 : issue-{Issue番号}-{内容の英語スラッグ}

※以下は絶対守ってほしいわけではないが、大きく内容がずれないようにして。

# タスク1 - カードごとのレイアウト自動保存

[完了イメージ]
- 読取矩形・テキスト・縦横比キープ・個別調整の上書きが、カードごとに自動保存される
- カードを切り替えて再度選択すると、保存済みの内容が復元される
- 保存済みレイアウトが無いカードは、従来通り既定値になる

# タスク2 - 一斉出力

[完了イメージ]
- 出力先フォルダパスのテキストボックスと「一斉出力」ボタンが追加される
- ボタン押下で、カード一覧の全カードのプレビュー画像がPNGとして一斉出力される
- 出力先フォルダパスは次回起動時も保持される

# タスク3 - 太字設定

[完了イメージ]
- 個別調整ダイアログに、フォント種類・サイズ・文字間隔と並んで太字のチェックボックスが追加される
- 統一設定・個別上書きどちらでも太字を切り替えられる
- タイトル・説明文はそれぞれ独立して太字を保持する

# タスク4 - 水平線

[完了イメージ]
- 説明文のある行が「---」のみの場合、プレビューではその行が水平線として描画される

# タスク5 - 複数フォントサイズの下揃え表示

[完了イメージ]
- 1行内でフォントサイズが異なる文字が混在する場合、下揃えで描画される

# タスク6 - 個別設定の色分け表示

[完了イメージ]
- 個別調整(文字区間ごとの上書き)が適用されている文字が、プレビュー画面上で色分け表示される
- 保存・一斉出力したPNGには反映されない(通常の色で出力される)

# タスク7 - 水平線の個別設定

[完了イメージ]
- 水平線の太さの既定値を1px細くする
- 説明文のテキストボックスで「---」を選択した状態で「調整」ボタンを押すと、
  太さ・上下Marginを変更するダイアログが開く

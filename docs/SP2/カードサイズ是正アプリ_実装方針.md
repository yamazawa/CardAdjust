# タスク1 - カードごとのレイアウト自動保存

[完了イメージ]
- 読取矩形・テキスト・縦横比キープ・個別調整の上書きが、カードごとに自動保存される
- カードを切り替えて再度選択すると、保存済みの内容が復元される
- 保存済みレイアウトが無いカードは、従来通り既定値になる

# タスク2 - 一斉出力

[完了イメージ]
- 出力先フォルダパスのテキストボックスと「一斉出力」ボタンが追加される
- ボタン押下で、カード一覧の全カードのプレビュー画像がPNGとして一斉出力される
- 出力先フォルダパスは次回起動時も保持される

# タスク3 - 太字設定

[完了イメージ]
- 個別調整ダイアログに、フォント種類・サイズ・文字間隔と並んで太字のチェックボックスが追加される
- 統一設定・個別上書きどちらでも太字を切り替えられる
- タイトル・説明文はそれぞれ独立して太字を保持する

# タスク4 - 水平線

[完了イメージ]
- 説明文のある行が「---」のみの場合、プレビューではその行が水平線として描画される

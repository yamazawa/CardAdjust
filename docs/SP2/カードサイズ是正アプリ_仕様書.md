# F. レイアウト保存

- 読取矩形(②③④の位置・サイズ)、②タイトル・④説明文のテキスト、\
  ③縦横比キープ有無、個別調整(文字区間ごとの上書き)を、カードごとに自動保存する
- 保存タイミングは操作の都度とする(アプリ全体設定と同じ自動保存の仕組みを使う)
- カードを選択したとき、保存済みレイアウトがあれば復元する
- 保存済みレイアウトが無いカードは、従来通り既定値(固定座標・空文字)にする

※統一レイアウト設定(フォント種類・サイズ・文字間隔・行間隔)は、\
　従来通りアプリ全体設定として保持し、カードごとには保存しない。

# G. 一斉出力

- 画面に出力先フォルダパスのテキストボックスと「一斉出力」ボタンを追加する
- 「一斉出力」ボタンを押すと、カード一覧の全カードについてプレビュー画像を合成し、\
  出力先フォルダへ`{ファイル名}.png`として一斉に保存する
- 保存済みレイアウトが無いカードは、既定値で合成する
- 出力先フォルダが存在しない場合は作成する
- 出力先フォルダパスはアプリ全体設定として保存し、次回起動時も保持する

# B. カード要素の設計(追加)

## ②タイトル・④説明文の太字

- 統一レイアウト設定に「太字」を追加する(②④それぞれ独立して保持する)
- 個別調整ダイアログでも、フォント種類・サイズ・文字間隔と同様に太字を上書きできる

## ④説明文の水平線

- 説明文のある行が「---」という文字列そのものである場合、\
  その行はテキストとして描画せず、水平線として描画する
- 太さ・上下の余白(Margin)を個別調整できる\
  → 説明文のテキストボックスで「---」を選択した状態で「調整」ボタンを押すと、\
  　太さ・上下Marginを変更するダイアログを開く

# H. 表示の改善

## 1行内のフォントサイズが異なる文字の縦位置

- 1行内で文字ごとにフォントサイズが異なる場合、上揃えではなく下揃えで描画する

## 個別設定の色分け表示

- 個別調整(文字区間ごとの上書き)が適用されている文字は、\
  プレビュー画面上で色を変えて表示する
- 保存・一斉出力したPNGには反映しない(通常の色で出力する)
